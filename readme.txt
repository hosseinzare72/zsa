افزونه فوق‌سبک مدیریت پورتفولیوی استودیوی ZSA — اپلیکیشن، بازی، وب‌سایت و محصول دیجیتال.

== Description ==

* ثبت نوع نوشته سفارشی zsa_project و طبقه‌بندی zsa_project_type با ترم‌های پیش‌فرض فارسی
* متاباکس‌های آکاردئونی RTL با پیش‌نمایش زنده
* شورت‌کد سراسری [zsa_portfolio] — هیرو، آمار، پروژه‌ها، نمونه‌کارهای وب، در‌توسعه و CTA در یک شورت‌کد
* شورت‌کدهای [zsa_projects] [zsa_web_portfolio] [zsa_coming_soon] [zsa_stats] [zsa_credit]
* قالب برگهٔ «تمام‌صفحه»: بدون هدر، فوتر، سایدبار، دیدگاه و مسیر صفحه؛ یا حالت سازگار CSS برای صفحه‌سازها
* بلوک گوتنبرگ با پنج حالت (پروژه‌ها، وب، در‌توسعه، آمار، صفحهٔ کامل)
* Schema.org خودکار (Organization + MobileApplication + WebSite)
* کش ترانزینت یک‌ساعته و سازگاری با WP Fastest Cache و LiteSpeed Cache
* ابزار مهاجرت اولیه یک‌کلیکی برای ساخت تمام پروژه‌های اولیه
* صفحه تنظیمات با تب‌های عمومی، نمایش، رنگ‌ها، تمام‌صفحه، متن‌ها و ابزارها
* بارگذاری شرطی CSS و JS فقط هنگام استفاده از شورت‌کد/بلوک
* کاملاً فارسی و RTL، سازگار با PHP 8.4 و آخرین نسخه وردپرس

== Installation ==

1. پوشه `zsa-portfolio-manager` را در مسیر `/wp-content/plugins/` آپلود کنید.
2. افزونه را از منوی «افزونه‌ها» فعال کنید.
3. پس از فعال‌سازی، به منوی «پورتفولیو ZSA > تنظیمات > ابزارها» بروید و روی «اجرای مهاجرت اولیه» کلیک کنید تا تمام پروژه‌های اولیه ساخته شوند.
4. در برگه ZSA Studio، بلوک HTML سفارشی قدیمی را با شورت‌کد `[zsa_portfolio]` جایگزین کنید.
5. برای تمام‌صفحه شدن برگه، در بخش «ویژگی‌های برگه → قالب» گزینهٔ **ZSA — تمام‌صفحه (بدون هدر/فوتر)** را انتخاب کنید. اگر از صفحه‌ساز استفاده می‌کنید، در تب «تمام‌صفحه» گزینهٔ «حذف هدر/فوتر قالب با CSS» را فعال کنید.

== Frequently Asked Questions ==

= آیا با صفحه‌سازهای سنگین مثل Elementor سازگار است؟ =

بله، اما توصیه نمی‌شود. طراحی برای گوتنبرگ و ویرایشگر بلوک بهینه شده است.

= آیا کش صفحه با WP Fastest Cache تداخل دارد؟ =

خیر. افزونه به‌صورت خودکار با WP Fastest Cache و LiteSpeed Cache هماهنگ است.

= چطور برگهٔ پورتفولیو را کاملاً تمام‌صفحه و بدون هدر/فوتر کنم؟ =

دو راه دارد: (۱) قالب برگهٔ «ZSA — تمام‌صفحه (بدون هدر/فوتر)» را در ویژگی‌های برگه انتخاب کنید — در این حالت افزونه یک سند HTML کامل و تمیز می‌سازد؛ (۲) اگر قالب برگه را نمی‌توانید عوض کنید (صفحه‌ساز/FSE)، در تب «تمام‌صفحه» گزینهٔ «حذف هدر/فوتر قالب با CSS» را فعال کنید یا در شورت‌کد بنویسید `[zsa_portfolio fullpage="1"]`.

= CSS و JS افزونه در صفحه‌ساز بارگذاری نمی‌شود =

در تب «عمومی» آدرس صفحه پورتفولیو را درست وارد کنید، یا در تب «تمام‌صفحه» گزینهٔ «بارگذاری همیشگی فایل‌ها» را فعال کنید. فیلتر `zsa_pm_is_zsa_page` هم برای تشخیص دستی در دسترس است.
